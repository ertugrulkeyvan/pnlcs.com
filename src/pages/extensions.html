The list is a file in this website’s repository. Free or paid, open or closed source: anything built for PNLCS can be listed. Sales happen on your own website.

Edit the list file Full instructions
  1. Open the list file on GitHubThe button opens it in the editor. GitHub makes a copy in your account the first time.
  2. Add your entryName, a short summary, the price type, the licence, the PNLCS version it works with and the page where people get it.
  3. Open a pull requestAn automatic check builds the site with your entry. A maintainer reviews it and merges.
