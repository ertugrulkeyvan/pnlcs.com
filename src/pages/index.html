What happens to a renewal

PNLCS runs billing on a schedule, so nobody has to remember to send an invoice or switch off an unpaid account. These are the defaults; every number is a setting.

Billing lifecycle in the docs

  1. 14 days before

    Renewal invoice

    Created and emailed to the customer.

    invoice_days_before_due = 14

  2. 3 days before

    Stored card charged

    If you turn auto-charge on. Up to 3 attempts, 3 days apart.

    AutoChargeDaysBefore = 3

  3. Due date

    Reminders

    Unpaid invoices turn overdue and reminder emails go out. An optional late fee applies after 3 days.

    LateFeeMinDays = 3

  4. 3 days after

    Suspended

    The service is suspended on the server. Paying unsuspends it within 30 minutes.

    AutoSuspensionDays = 3

  5. 30 days after

    Terminated

    Only if you enable it. Off by default.

    AutoTerminationDays = 30

Install with Docker

One application container and one database container. The install wizard does the rest.

  1. Start the containersReplace changeme with your own passwords first.
  2. Wait 3 to 5 minutesThe first start installs dependencies and builds the frontend.
  3. Open /installThe wizard checks requirements, creates your admin account, then locks itself.

Other ways to installOr try the live demo first

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
