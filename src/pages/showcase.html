The showcase is a file in this website’s repository. GitHub can open a pull request for you from the browser; you do not need to install anything.

Edit the showcase file Full instructions
  1. Open the showcase file on GitHubThe button opens it in the editor. GitHub makes a copy in your account the first time.
  2. Add your entryName, website, what you sell and the modules you run. Keep the description under 400 characters.
  3. Open a pull requestAn automatic check builds the site with your entry. A maintainer reviews it and merges.
