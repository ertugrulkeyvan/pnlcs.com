Your first pull request

  1. Pick something smallAn open issue, or something that bothered you in the demo.
  2. Fork and branchRun the project locally with Docker, following the docs.
  3. Open a pull requestSay what you changed and why. Small pull requests are reviewed fastest.
  4. Get it mergedA maintainer reviews it. Merged changes go into the next release, and you are credited in the history.

Talk to us

  • IssuesBugs and concrete feature requests, with steps to reproduce.
  • DiscussionsQuestions, ideas and show-and-tell.
  • ForumThe Panelica community forum.
  • Security reportsPrivately, by email. Never in a public issue.

This is a side project for the maintainers, so replies are not always same-day. Reproduction steps or a patch help enormously. Please follow the code of conduct.
