VPS on Proxmox VE

Connect a Proxmox VE server, install official cloud images from the admin panel and sell VPS products. When the invoice is paid, PNLCS clones, configures and starts the server; the customer manages it from the client portal.

Destructive actions ask first

Anything that wipes data asks for the server’s name. Long jobs, like a reinstall or a restore, run in the background and finish even if the page is closed.

Machines PNLCS did not create are left alone

A hypervisor usually runs more than customer servers. These rules keep PNLCS to its own.

  • Every server PNLCS creates carries a tag and a note naming its service; it acts only on machines with that mark
  • The recommended API token reaches only its own pool, and the connection test warns about rights billing never needs
  • Servers are created with deletion protection, lifted only at the moment of termination
  • Customers never see the hypervisor’s address
