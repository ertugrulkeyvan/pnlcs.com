    The Appearance screen

    Every installed theme appears with its preview under Appearance. Activate one, and the storefront and client portal change together.

    Build your own theme

    A theme is a folder with a theme.json, a stylesheet and optional view overrides. Package it as a zip and install it from the admin panel.
