サイトを訪問したとき

本サイトは Cloudflare を通じて配信されており、ページの配信と攻撃の遮断のために Cloudflare があなたの IP アドレスとブラウザ情報を受け取ります。ブラウザは他のサービスからもいくつかのものを読み込みます：

  • Google Fonts のフォント
  • GitHub と shields.io から取得するプロジェクトの数値とコントリビューターの画像
  • Google Tag Manager（それ自体は Cookie を保存せず、同意後にのみ下記のツールを読み込みます）

ブラウザがこれらのサービスに接続すると、IP アドレスが相手に伝わります。pnlcs.com 用の Cookie は保存されません。

Cookie と計測

同意いただいた場合、本サイトはページの利用状況を把握するために Google Analytics と Microsoft Clarity を、広告の計測のために Meta Pixel を使用します。これらは Cookie を保存し、利用データを Google、Microsoft、Meta に送信します。「同意する」を選ぶまで、いずれも動作しません。

選択内容はブラウザのローカルストレージに保存されるため、ページごとに同じ質問は表示されません。いつでも変更できます。
