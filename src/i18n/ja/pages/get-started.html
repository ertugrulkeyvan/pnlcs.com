PNLCSを動かす

PNLCSはLaravelアプリケーションです。PHP 8.4、MySQLまたはMariaDB、Webサーバーがあればどこでも動作します。まず中身を見てみたい場合は、実際のインストール環境である ライブデモ をご覧ください。

Dockerでクイックスタート

公式イメージにはPHP-FPM 8.4、nginx、Node.js 20、supervisorが含まれており、初回起動時に最新のコードを取得します。

  1. コンテナを起動する先に changeme を独自のパスワードに置き換えてください。
  2. 3〜5分待つ初回起動時に依存パッケージのインストールとフロントエンドのビルドが行われます。
  3. /installを開くウィザードが要件を確認し、管理者アカウントを作成したあと、自動的にロックされます。

DockerガイドDocker Hubのイメージ

ターミナル
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4

動作要件

小規模な環境なら、データベースを同じマシンに置いても2 GBのメモリで余裕を持って動作します。

動作要件の詳細

PHP8.4以降
データベースMySQL 8.0またはMariaDB 10.6+
WebサーバーNginxまたはApache（PHP-FPM使用）
Node.js18+（20 LTS推奨）、フロントエンドのビルド時のみ必要
Composer2.x
メモリ小規模なら1 GBで動作、2 GBあれば余裕があります
ディスクアプリ本体は約130 MB。データの増加に備えて2 GB以上の空きを確保してください

インストール後にすること

  • 初期設定チェックリスト会社情報、メール、決済ゲートウェイ、サーバー、最初の商品。
  • 最初の販売空のカタログから、支払い済みでプロビジョニングされた注文まで。
  • セキュリティチェックリストHTTPS、デバッグの無効化、スタッフの二要素認証、サーバー外へのバックアップ。
  • アップデートデータを失わずに最新リリースを取得します。
  • バックアップアプリケーションキーを含め、バックアップすべきもの。
  • FAQよくある質問。
