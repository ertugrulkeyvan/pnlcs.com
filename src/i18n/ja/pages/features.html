顧客ポータル

顧客がログイン後に目にする画面です。

ホスティングツール
ショップと購入手続き
プランの閲覧、サービスの構成、クーポンの適用、支払い。
サービス管理
アップグレード、ダウングレード、解約、自動更新の切り替え。
ドメイン
登録、移管、更新。EPPコードとWHOIS。
請求書
オンライン支払い、PDFのダウンロード、入金、クレジット残高の利用。
見積書
販売前の見積書を確認して承認できます。承認された見積書は請求書になります。
銀行振込の通知
オフラインでの支払いを、領収書をアップロードして報告できます。
SSL証明書
CSRの生成、承認者メール、自動インストール。
サポートとナレッジベース
添付ファイル付きのチケット、検索可能なナレッジベース、お知らせ。
ネットワークの状態
発生中の障害と計画メンテナンス。
アカウントのセキュリティ
二要素認証、ログイン通知、セッション履歴。

請求管理と自動化

サービスは、サーバーモジュールが成功を報告してから有効化されます。

定期請求
月払い、四半期払い、半年払い、年払い、2年払いのサイクル。
自動利用停止
未払いのサービスは、設定した猶予期間の後に停止されます。
通知メール
請求書、支払い、カードの有効期限、ドメイン更新のメール。
税ルール
国や州ごとに設定でき、納税額レポートも出力できます。
ひとつの決済エンジン
決済ゲートウェイ、手動の支払い、クレジットはすべて同じ処理を通ります。一部支払いや、過払い分のクレジット化にも対応します。
返金
全額または一部。ゲートウェイのAPI経由で処理するか、オフラインの返金として記録します。
確実なプロビジョニング
失敗した処理はキューに入り自動で再試行され、スタッフに通知されます。
従量課金
ディスクと帯域幅の超過分。商品ごとに有効化します。
延滞料、クーポン、プロモーション
クレジット残高と入金機能もあります。
定期メンテナンス処理
為替レートの更新、データベースのバックアップ、ログの保持期間管理をスケジュール実行します。

管理パネル

スタッフが毎日使う画面です。

ダッシュボード
売上、新規登録、保留中の注文、未対応のチケットをひと目で確認できます。
顧客
プロフィール、メモ、請求の概要、顧客としてのログイン。
注文と請求書
手動作成、一括操作、一斉メール、PDFエクスポート。
商品とバンドル
構成オプション、アドオン、価格表。
ヘルプデスク
社内メモ、エスカレーションルール、スパムフィルター、定型返信。
レポート
27種類を標準搭載：収益、予測、継続率、チケット、ドメイン、税。
見積とプロジェクト
WHMCSと同様の販売前フロー。
カレンダー
イベント、リマインダー、スケジュールされたタスク。

セキュリティとアクセス制御

スタッフには役割で許可された範囲だけが表示され、管理操作はすべて記録されます。

セキュリティポリシー
役割と権限
45を超える細かな権限による、役割ベースのアクセス制御。
二要素認証
スタッフと顧客の両方に対応し、スタッフにはリカバリーコードがあります。
レート制限
ログイン、2FAの確認、パスワードリセット、メールの再送信に適用されます。
管理画面のIP許可リスト
管理エリア向けのオプション機能です。
セッション
タイムアウトと強制ログアウト。
操作ログ
すべての管理操作を記録します。IPアドレスとメールアドレスのブロックにも対応します。

言語

30のロケールに対応し、翻訳はブラウザ上で編集できます。

30のロケール
デフォルトでは英語が有効です。その他の言語は必要に応じて有効にできます。
ブラウザ上のエディター
2,232のインターフェース文字列を、ファイルに触れずに変更できます。
AIによる翻訳支援
未翻訳のキーを一括で埋めてから、内容を確認できます。
インポートとエクスポート
ロケールごとのJSON形式で、使い慣れたツールで作業したい翻訳者に対応します。

開発者向け

管理エリアでできることは、すべてAPIでスクリプト化できます。

開発者ガイド
HTTP API
WHMCSと同じアクション名を持つ171のアクションと、OpenAPI 3.1定義。
MCPサーバー
AIアシスタントがAPIを通じて情報を読み取り、許可すれば操作も行えます。
フック
WHMCS互換のadd_hook()と20以上のフックポイント。フックが失敗しても請求処理は止まりません。
Webhook
決済ゲートウェイからの受信コールバックと、送信イベント。
モジュール
サーバー、決済ゲートウェイ、レジストラ、SSLの各モジュールと、アドオン。
メールパイプ
IMAPまたはPOP3のメールボックスに届いたメールを、チケットや返信に変換します。
