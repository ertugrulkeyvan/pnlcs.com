ホスティング事業者のためのオープンソース請求管理

無料で使える、セルフホスト型のWHMCS代替です。 請求書発行、ドメイン、SSL、サポートチケット、共用ホスティング、Dockerアプリ、Proxmox VPSをひとつのアプリケーションで扱えます。Panelicaチームとボランティアがメンテナンスしています。

更新時に起きること

PNLCSは請求処理をスケジュールに沿って実行するため、請求書の送付や未払いアカウントの停止を誰かが覚えておく必要はありません。以下はデフォルト値で、数値はすべて設定で変更できます。

ドキュメントの請求ライフサイクル

  1. 14日前

    更新請求書

    作成され、顧客にメールで送信されます。

    invoice_days_before_due = 14

  2. 3日前

    登録済みカードへの課金

    自動課金を有効にした場合に行います。3日間隔で最大3回試行します。

    AutoChargeDaysBefore = 3

  3. 支払期日

    督促

    未払いの請求書は期限切れとなり、督促メールが送信されます。3日経過後に任意の延滞料が加算されます。

    LateFeeMinDays = 3

  4. 3日後

    利用停止

    サーバー上のサービスが停止されます。支払いが行われると30分以内に停止が解除されます。

    AutoSuspensionDays = 3

  5. 30日後

    解約

    有効にした場合のみ実行されます。デフォルトではオフです。

    AutoTerminationDays = 30

Dockerでインストール

アプリケーションのコンテナが1つと、データベースのコンテナが1つ。あとはインストールウィザードが行います。

  1. コンテナを起動する先に changeme を独自のパスワードに置き換えてください。
  2. 3〜5分待つ初回起動時に依存パッケージのインストールとフロントエンドのビルドが行われます。
  3. /installを開くウィザードが要件を確認し、管理者アカウントを作成したあと、自動的にロックされます。

その他のインストール方法または、先にライブデモを試す

ターミナル
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
