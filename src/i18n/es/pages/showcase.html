Los casos reales son un archivo del repositorio de este sitio web. GitHub puede abrir el pull request por ti desde el navegador; no necesitas instalar nada.

Editar el archivo de casos reales Instrucciones completas
  1. Abre el archivo de casos reales en GitHubEl botón lo abre en el editor. La primera vez, GitHub crea una copia en tu cuenta.
  2. Añade tu entradaNombre, sitio web, qué vendes y los módulos que usas. La descripción debe tener menos de 400 caracteres.
  3. Abre un pull requestUna comprobación automática genera el sitio con tu entrada. Un mantenedor la revisa y la fusiona.
