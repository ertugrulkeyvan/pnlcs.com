Añade tu módulo o tema

La lista es un archivo del repositorio de este sitio. Gratis o de pago, código abierto o cerrado: todo lo hecho para PNLCS puede listarse. Las ventas se hacen en tu propio sitio web.

Editar el archivo de la lista Instrucciones completas
  1. Abre el archivo de la lista en GitHubEl botón lo abre en el editor. La primera vez, GitHub crea una copia en tu cuenta.
  2. Añade tu entradaNombre, un resumen corto, el tipo de precio, la licencia, la versión de PNLCS con la que funciona y la página donde se consigue.
  3. Abre un pull requestUna comprobación automática genera el sitio con tu entrada. Un mantenedor la revisa y la fusiona.
