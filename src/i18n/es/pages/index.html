Qué pasa con una renovación

PNLCS ejecuta la facturación de forma programada, así nadie tiene que acordarse de enviar una factura ni de desactivar una cuenta impagada. Estos son los valores por defecto; cada número es un ajuste.

Ciclo de facturación en la documentación

  1. 14 días antes

    Factura de renovación

    Se crea y se envía por correo al cliente.

    invoice_days_before_due = 14

  2. 3 días antes

    Cobro a la tarjeta guardada

    Si activas el cobro automático. Hasta 3 intentos, con 3 días entre cada uno.

    AutoChargeDaysBefore = 3

  3. Fecha de vencimiento

    Recordatorios

    Las facturas impagadas pasan a vencidas y se envían correos de recordatorio. Tras 3 días se aplica un recargo por demora opcional.

    LateFeeMinDays = 3

  4. 3 días después

    Suspendido

    El servicio se suspende en el servidor. Al pagar, se reactiva en menos de 30 minutos.

    AutoSuspensionDays = 3

  5. 30 días después

    Cancelado

    Solo si lo activas. Desactivado por defecto.

    AutoTerminationDays = 30

Instalación con Docker

Un contenedor de aplicación y un contenedor de base de datos. El asistente de instalación hace el resto.

  1. Inicia los contenedoresAntes, sustituye changeme por tus propias contraseñas.
  2. Espera de 3 a 5 minutosEl primer arranque instala las dependencias y compila el frontend.
  3. Abre /installEl asistente comprueba los requisitos, crea tu cuenta de administrador y después se bloquea.

Otras formas de instalarO prueba antes la demo en vivo

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
