基于 Proxmox VE 的 VPS

接入一台 Proxmox VE 服务器，在管理后台中安装官方云镜像，即可销售 VPS 产品。账单付款后，PNLCS 会克隆、配置并启动服务器，客户在客户中心进行管理。

客户可以做什么

功能说明
电源开机、重启、关机（一分钟内无响应则强制关机）、强制断电、重置
实时状态CPU、内存、运行时间、IP 地址和磁盘使用率
图表CPU、内存、网络和磁盘数据，来自 Proxmox 自身的统计
Root 密码通过 guest agent 立即设置，否则在下次启动时生效
重装系统可选择产品提供的任意系统；虚拟机、MAC 和 IP 地址保持不变
快照创建、回滚和删除，数量以套餐规定为上限
备份备份到本地存储或 Proxmox Backup Server；支持还原和删除

破坏性操作会先确认

任何会清除数据的操作，都需要输入服务器名称确认。重装、还原等耗时任务在后台运行，即使关闭页面也会执行完毕。

每个计费事件触发时 PNLCS 执行的操作

事件在 Proxmox 上
订单已付款使用下一个可用的 VM ID 克隆到资源池，应用 cloud-init 配置，扩容磁盘，开启保护，然后启动
暂停先关闭开机自启，再关机，这样宿主机重启后也不会重新启动
解除暂停开启开机自启，然后启动
终止停止，解除保护，连同磁盘一起删除；IP 地址回收到地址池
升级调整 CPU 核心数和内存；磁盘只扩容，从不缩小
每小时从 Proxmox 的统计中读取磁盘用量和本月流量

不是 PNLCS 创建的机器，它不会碰

一台虚拟化主机上通常不只有客户的服务器。以下规则确保 PNLCS 只管理自己创建的机器。

  • PNLCS 创建的每台服务器都带有一个标签和一条注明所属服务的备注；它只操作带有该标记的机器
  • 推荐使用的 API 令牌只能访问自己的资源池，连接测试会对计费系统用不到的权限发出警告
  • 服务器创建时即开启删除保护，只在终止的那一刻才解除
  • 客户永远看不到虚拟化主机的地址
