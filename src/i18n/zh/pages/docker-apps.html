Docker 应用

客户从应用目录中安装 WordPress、n8n、数据库或远程桌面。每个应用都以 Docker 容器的形式运行在客户的主机账户内，受其套餐的内存和 CPU 限制。需要一台 Panelica 服务器。

Docker 应用销售指南

三种销售方式

可以组合使用。

主机附带应用
普通主机套餐，另带一定的容器配额。客户拥有一个网站，并可随时在“应用”标签页中添加应用。
应用托管
订单会在客户的域名上安装一个应用。你可以固定应用（例如“托管 WordPress”），也可以让客户从你的目录中选择，这样一个产品就能覆盖所有应用。
容器套餐
只提供资源，不含网站：没有域名，服务页面只显示“应用”标签页。

每个账户的所有应用共享一个 cgroup 限额

客户启动的每个容器都创建在其账户的 cgroup slice 中。2 GB 套餐的客户，所有应用加起来共用 2 GB，无法占用其他客户的内存。

  • 不允许特权容器、额外的 capabilities 或挂载宿主机路径，计费系统的密钥也不例外
  • 套餐规定应用数量、总内存和总 CPU
  • 客户下单前就能看到应用所需的内存
  • 应用安装失败的订单会被回滚，不会留下半成品

应用目录由你来管理

有哪些应用由 Panelica 服务器决定，怎么卖由 PNLCS 决定：提供哪些应用、推荐哪些、排列顺序、宣传语和 logo。

  1. 接入 Panelica 服务器使用带有 Docker 权限范围的 API 密钥。
  2. 选择销售方式主机附带、应用托管或容器套餐。
  3. 创建产品设置容器配额、内存和 CPU，再设定价格。
  4. 整理应用目录上架、推荐和排序应用；98 个应用中有 95 个自带 logo。
