客户中心

客户登录后看到的内容。

主机管理工具
购物与结账
浏览套餐、配置服务、使用优惠券、付款。
服务管理
升级、降级、取消以及开关自动续费。
域名
注册、转入和续费；EPP 转移码和 WHOIS。
账单
在线支付、下载 PDF、充值、使用账户余额。
报价单
查看并接受售前报价单；接受后的报价单会转为账单。
银行转账通知
上传付款凭证，报告线下付款。
SSL 证书
生成 CSR、选择验证邮箱、自动安装。
技术支持与知识库
支持附件的工单、可搜索的知识库和公告。
网络状态
当前故障和计划维护。
账户安全
双因素登录、登录提醒和会话记录。

计费与自动化

只有在服务器模块报告成功后，服务才会激活。

周期计费
月付、季付、半年付、年付和两年付。
自动暂停
未付款的服务在你设定的宽限期后被暂停。
提醒
账单、付款、银行卡到期和域名续费邮件。
税务规则
按国家和州/省设置，并提供应缴税额报表。
统一的支付引擎
支付网关、手动付款和余额支付走同一套流程，支持部分付款，多付金额转入余额。
退款
全额或部分退款，可通过支付网关 API 退款，也可记录线下退款。
可靠的开通
失败的操作会进入队列并自动重试，同时通知员工。
用量计费
磁盘和带宽超额计费，可按产品单独开启。
滞纳金、优惠券、促销
另有账户余额和充值流程。
定期维护任务
按计划更新汇率、备份数据库和清理日志。

管理后台

员工每天使用的功能。

仪表盘
收入、注册、待处理订单和未关闭工单一目了然。
客户
客户资料、备注、账务摘要，以及以客户身份登录。
订单和账单
手动创建、批量操作、群发邮件、导出 PDF。
产品和组合套餐
可配置选项、附加项和价格矩阵。
工单系统
内部备注、升级规则、垃圾邮件过滤、预设回复。
报表
内置 27 种：收入、预测、客户留存、工单、域名、税务。
报价单和项目
WHMCS 风格的售前流程。
日历
事件、提醒和计划任务。

安全与访问控制

员工只能看到角色允许的内容；每一项管理操作都有记录。

安全政策
角色和权限
基于角色的访问控制，提供 45 项以上的细粒度权限。
双因素认证
员工和客户均可使用，员工另有恢复码。
频率限制
适用于登录、2FA 验证、密码重置和邮件重发。
管理后台 IP 白名单
可选，用于管理后台。
会话
超时和强制退出。
操作日志
记录每一项管理操作；可封禁 IP 和邮箱。

语言

30 种语言；可在浏览器中编辑翻译。

30 种语言
默认启用英语，其他语言按需开启。
浏览器内编辑器
无需改动文件，即可修改 2,232 条界面文本中的任意一条。
AI 辅助翻译
批量补全缺失的翻译，再进行审核。
导入和导出
每种语言一个 JSON 文件，方便习惯用自己工具的译者。

开发者

管理后台中的所有操作都可以通过 API 脚本化。

开发者指南
HTTP API
171 个操作，沿用 WHMCS 的操作名称，并提供 OpenAPI 3.1 描述文件。
MCP 服务器
让 AI 助手通过 API 读取数据，经你允许后还可以执行操作。
钩子
兼容 WHMCS 的 add_hook() 函数，提供 20 多个钩子点；钩子出错不会影响计费。
Webhook
接收支付网关回调，并向外发送事件。
模块
服务器、支付网关、域名注册商和 SSL 模块，以及插件。
邮件导入工单
从 IMAP 或 POP3 邮箱收取邮件，转为工单和回复。
