集成状态
  • cPanel、Plesk 和 DirectAdmin在你的面板上运行服务器模块，把结果告诉我们。
  • PayPal、Authorize.net、银行转账完整走一遍测试付款流程。
  • Enom通过真实 API 注册并续费一个域名。
  • WHMCS 导入工具目前还没有。可以从迁移指南入手。

你的第一个 pull request

  1. 从小事做起一个未解决的 issue，或者你在演示中觉得别扭的地方。
  2. Fork 并创建分支按照文档，用 Docker 在本地运行项目。
  3. 提交 pull request说明你改了什么、为什么改。改动越小，审核越快。
  4. 合并维护者会进行审核。合并后的改动会进入下一个版本，提交历史中会保留你的署名。
