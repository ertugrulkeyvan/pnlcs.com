运行 PNLCS

PNLCS 是一个 Laravel 应用，只要有 PHP 8.4、MySQL 或 MariaDB 和 Web 服务器就能运行。想先看看的话， 在线演示 就是一套真实的安装。

方式适用场景耗时指南
Docker试用 PNLCS，或以单个容器运行约 5 分钟命令
自己的服务器VPS 或独立服务器：Ubuntu、Debian、AlmaLinux 或 Rocky约 30 分钟指南
装在主机面板中已经运行 Panelica、cPanel 或类似面板的服务器约 20 分钟指南

使用 Docker 快速开始

官方镜像内置 PHP-FPM 8.4、nginx、Node.js 20 和 supervisor，首次启动时会拉取最新代码。

  1. 启动容器先将 changeme 替换为你自己的密码。
  2. 等待 3 到 5 分钟首次启动会安装依赖并构建前端。
  3. 打开 /install安装向导会检查环境要求、创建管理员账户，然后自动锁定。

Docker 指南Docker Hub 上的镜像

终端
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4

系统要求

小规模安装时，数据库和应用在同一台机器上，2 GB 内存就很宽裕。

完整系统要求

PHP8.4 或更高版本
数据库MySQL 8.0 或 MariaDB 10.6+
Web 服务器Nginx 或 Apache，搭配 PHP-FPM
Node.js18+（推荐 20 LTS），仅用于构建前端
Composer2.x
内存小规模安装 1 GB 即可运行；2 GB 更宽裕
磁盘应用本身约 130 MB；考虑到数据增长，至少预留 2 GB 空闲空间

安装之后

  • 配置清单公司信息、邮件、支付网关、服务器和第一个产品。
  • 第一笔销售从空的产品目录，到一笔已付款、已开通的订单。
  • 安全检查清单HTTPS、关闭调试模式、员工启用双因素认证、备份存放到服务器之外。
  • 更新拉取最新版本，数据不会丢失。
  • 备份需要备份哪些内容，包括应用密钥。
