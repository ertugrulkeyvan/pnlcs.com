当你访问本站时

本站通过 Cloudflare 提供服务，Cloudflare 会收到你的 IP 地址和浏览器信息，用于传送页面和拦截攻击。你的浏览器还会从其他服务加载一些内容：

  • 来自 Google Fonts 的字体
  • 来自 GitHub 和 shields.io 的项目数据和贡献者头像
  • Google Tag Manager：它本身不设置 Cookie，只有在你接受后才会加载下面的工具

你的浏览器连接这些服务时，它们会看到你的 IP 地址。它们不会为 pnlcs.com 设置 Cookie。

Cookie 与统计

在你同意后，本站使用 Google Analytics 和 Microsoft Clarity 了解页面的使用情况，并使用 Meta Pixel 衡量广告效果。它们会设置 Cookie，并把使用数据发送给 Google、Microsoft 和 Meta。在你选择“接受”之前，这些都不会运行。

你的选择保存在浏览器的本地存储中，因此不会在每个页面重复询问。你可以随时更改。

初步沟通表单

当你提交初步沟通表单时，你的姓名、邮箱、公司、国家和留言会通过 Web3Forms 以邮件形式发送给 PNLCS 团队。这些信息只用于回复你和准备报价，不再需要时即删除；如果你提出要求，也会提前删除。

你的权利

你可以随时要求获取数据副本、更正或删除数据，反对数据的使用，或撤回你的同意。你也可以向所在地的数据保护机构投诉。

此类请求联系： info@panelica.com
