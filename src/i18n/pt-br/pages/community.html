Seu primeiro pull request

  1. Escolha algo pequenoUma issue aberta ou algo que incomodou você na demonstração.
  2. Faça um fork e crie um branchRode o projeto localmente com Docker, seguindo a documentação.
  3. Abra um pull requestDiga o que você alterou e por quê. Pull requests pequenos são revisados mais rápido.
  4. Tenha seu código incorporadoUm mantenedor faz a revisão. As alterações aceitas entram na próxima versão, e você recebe o crédito no histórico.
