Coloque o PNLCS para rodar

O PNLCS é uma aplicação Laravel. Ele roda em qualquer ambiente com PHP 8.4, MySQL ou MariaDB e um servidor web. Se quiser conhecer antes, a demonstração ao vivo é uma instalação real.

Três formas de instalar

Início rápido com Docker

A imagem oficial inclui PHP-FPM 8.4, nginx, Node.js 20 e supervisor, e baixa o código mais recente na primeira inicialização.

  1. Inicie os contêineresAntes, substitua changeme pelas suas próprias senhas.
  2. Aguarde de 3 a 5 minutosA primeira inicialização instala as dependências e compila o frontend.
  3. Abra /installO assistente verifica os requisitos, cria sua conta de administrador e depois se bloqueia.

Guia do DockerImagem no Docker Hub

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4

Requisitos

Uma instalação pequena roda com folga em 2 GB de memória, com o banco de dados na mesma máquina.

Requisitos completos

PHP8.4 ou mais recente
Banco de dadosMySQL 8.0 ou MariaDB 10.6+
Servidor webNginx ou Apache com PHP-FPM
Node.js18+ (20 LTS recomendado), apenas para compilar o frontend
Composer2.x
Memória1 GB funciona para uma instalação pequena; 2 GB dá folga
DiscoCerca de 130 MB para a aplicação; reserve pelo menos 2 GB livres, já que os dados crescem

Depois de instalar

  • Checklist de configuraçãoDados da empresa, e-mail, um gateway, um servidor e seu primeiro produto.
  • Sua primeira vendaDe um catálogo vazio a um pedido pago e provisionado.
  • Checklist de segurançaHTTPS, debug desativado, dois fatores para a equipe, backups guardados fora do servidor.
  • AtualizaçãoBaixe a versão mais recente sem perder dados.
  • BackupsO que incluir no backup, inclusive a chave da aplicação.
  • Perguntas frequentesDúvidas comuns.
