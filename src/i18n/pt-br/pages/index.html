O que acontece em uma renovação

O PNLCS executa o faturamento de forma agendada, então ninguém precisa lembrar de enviar uma fatura ou desligar uma conta inadimplente. Estes são os valores padrão; cada número é uma configuração.

Ciclo de faturamento na documentação

  1. 14 dias antes

    Fatura de renovação

    Gerada e enviada por e-mail ao cliente.

    invoice_days_before_due = 14

  2. 3 dias antes

    Cobrança no cartão salvo

    Se você ativar a cobrança automática. Até 3 tentativas, com 3 dias de intervalo.

    AutoChargeDaysBefore = 3

  3. Vencimento

    Lembretes

    Faturas não pagas passam a constar como vencidas e os e-mails de lembrete são enviados. Uma multa por atraso opcional é aplicada após 3 dias.

    LateFeeMinDays = 3

  4. 3 dias depois

    Suspenso

    O serviço é suspenso no servidor. Ao pagar, ele é reativado em até 30 minutos.

    AutoSuspensionDays = 3

  5. 30 dias depois

    Encerrado

    Somente se você ativar. Desativado por padrão.

    AutoTerminationDays = 30

Instale com Docker

Um contêiner de aplicação e um contêiner de banco de dados. O assistente de instalação faz o resto.

  1. Inicie os contêineresAntes, substitua changeme pelas suas próprias senhas.
  2. Aguarde de 3 a 5 minutosA primeira inicialização instala as dependências e compila o frontend.
  3. Abra /installO assistente verifica os requisitos, cria sua conta de administrador e depois se bloqueia.

Outras formas de instalarOu teste antes a demonstração ao vivo

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
