Tüm özellikler

Bir yenileme sürecinde neler olur

PNLCS faturalandırmayı zamanlanmış görevlerle yürütür; kimsenin fatura göndermeyi ya da ödenmemiş bir hesabı kapatmayı hatırlaması gerekmez. Aşağıdakiler varsayılan değerlerdir; her sayı bir ayardır.

Dokümantasyonda faturalandırma döngüsü

  1. 14 gün önce

    Yenileme faturası

    Oluşturulur ve müşteriye e-postayla gönderilir.

    invoice_days_before_due = 14

  2. 3 gün önce

    Kayıtlı karttan tahsilat

    Otomatik tahsilatı açtıysanız. 3 gün arayla en fazla 3 deneme.

    AutoChargeDaysBefore = 3

  3. Son ödeme tarihi

    Hatırlatmalar

    Ödenmemiş faturalar gecikmiş duruma geçer ve hatırlatma e-postaları gönderilir. İsteğe bağlı gecikme ücreti 3 gün sonra uygulanır.

    LateFeeMinDays = 3

  4. 3 gün sonra

    Askıya alınır

    Hizmet sunucuda askıya alınır. Ödeme yapıldığında 30 dakika içinde yeniden açılır.

    AutoSuspensionDays = 3

  5. 30 gün sonra

    Sonlandırılır

    Yalnızca siz etkinleştirirseniz. Varsayılan olarak kapalıdır.

    AutoTerminationDays = 30

Docker ile kurulum

Bir uygulama container'ı ve bir veritabanı container'ı. Gerisini kurulum sihirbazı halleder.

  1. Container'ları başlatınÖnce changeme değerlerini kendi şifrelerinizle değiştirin.
  2. 3 ila 5 dakika bekleyinİlk açılışta bağımlılıklar kurulur ve frontend derlenir.
  3. /install adresini açınSihirbaz gereksinimleri kontrol eder, yönetici hesabınızı oluşturur ve ardından kendini kilitler.

Diğer kurulum yollarıYa da önce canlı demoyu deneyin

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
