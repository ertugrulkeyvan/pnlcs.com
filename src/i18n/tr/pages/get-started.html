Docker ile hızlı başlangıç

Resmî imaj PHP-FPM 8.4, nginx, Node.js 20 ve supervisor içerir; ilk açılışta en güncel kodu indirir.

  1. Container'ları başlatınÖnce changeme değerlerini kendi şifrelerinizle değiştirin.
  2. 3 ila 5 dakika bekleyinİlk açılışta bağımlılıklar kurulur ve frontend derlenir.
  3. /install adresini açınSihirbaz gereksinimleri kontrol eder, yönetici hesabınızı oluşturur ve ardından kendini kilitler.

  2. Uygulamayı kurun

    PNLCS dizini web sunucusu kullanıcısına aittir ve her composer, artisan ve npm komutu bu kullanıcıyla çalıştırılır. pn yardımcısı bunu sizin yerinize yapar. Dizin root kullanıcısına aitse kurulum sihirbazı ve sonraki güncellemeler başarısız olur.

    Tek bir veritabanı şifresi seçin ve bunu hem CREATE USER komutunda hem de .env satırında kullanın. pn yardımcısı yalnızca geçerli kabuk oturumu boyunca tanımlı kalır; yeniden giriş yaptıktan sonra onu tekrar tanımlayın.

    Şu komutu çalıştırmayın: db:seed. Kurulum sihirbazı veritabanına başlangıç verilerini yükler ve seçtiğiniz yöneticiyi oluşturur.

    Terminal
    $ sudo git clone https://github.com/Panelica/pnlcs.git /var/www/pnlcs
$ sudo chown -R www-data:www-data /var/www/pnlcs
$ cd /var/www/pnlcs
$ pn() { sudo -u www-data HOME=/tmp/pnlcs-home COMPOSER_HOME=/tmp/pnlcs-home/composer "$@"; }

$ pn composer install --no-dev --optimize-autoloader --no-interaction

$ sudo mysql -e "CREATE DATABASE pnlcs CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'pnlcs'@'localhost' IDENTIFIED BY 'choose-a-strong-password';
  GRANT ALL PRIVILEGES ON pnlcs.* TO 'pnlcs'@'localhost'; FLUSH PRIVILEGES;"

$ pn cp .env.example .env
$ pn sed -i 's|^APP_URL=.*|APP_URL=http://example.com|; s|^DB_PASSWORD=.*|DB_PASSWORD=choose-a-strong-password|' .env
$ sudo chmod 640 .env

$ pn php artisan key:generate
$ pn php artisan migrate --force
$ pn npm ci
$ pn npm run build
$ pn php artisan storage:link
$ pn php artisan optimize

  3. Nginx'i public/ dizinine yönlendirin

    Belge kök dizini public/ dizinidir, asla proje kök dizini değildir, çünkü proje kök dizininde şu dosya bulunur: .env. Varsayılan siteyi kaldırın; aksi halde sunucunun adresi Nginx karşılama sayfasını göstermeye devam eder.

    Apache ve Caddy de aynı kurallarla çalışır: belge kök dizini public/, PHP için PHP-FPM 8.4 ve dosya olmayan her istek şuraya yönlendirilir: index.php.

    Terminal
    $ sudo tee /etc/nginx/sites-available/pnlcs > /dev/null <<'EOF'
server {
    listen 80;
    server_name example.com;
    root /var/www/pnlcs/public;
    index index.php;
    charset utf-8;
    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.4-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
    location ~ /\.(?!well-known).* { deny all; }
}
EOF
$ sudo ln -s /etc/nginx/sites-available/pnlcs /etc/nginx/sites-enabled/
$ sudo rm -f /etc/nginx/sites-enabled/default
$ sudo nginx -t && sudo systemctl reload nginx
    Terminal
    $ sudo tee /etc/nginx/conf.d/pnlcs.conf > /dev/null <<'EOF'
server {
    listen 80;
    server_name example.com;
    root /var/www/pnlcs/public;
    index index.php;
    charset utf-8;
    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    location ~ \.php$ {
        fastcgi_pass unix:/run/php-fpm/www.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
    location ~ /\.(?!well-known).* { deny all; }
}
EOF
$ sudo nginx -t && sudo systemctl reload nginx

  4. Tarayıcıda tamamlayın, ardından zamanlamayı ve güvenliği ayarlayın

    Tarayıcıda şu adresi açın: http://example.com/install. Sihirbaz gereksinimleri kontrol eder, yöneticinizi oluşturur ve ardından kendini kapatır.

    Web sunucusu kullanıcısı için tek bir cron satırı faturaları, hatırlatmaları, askıya almaları, SSL kontrollerini ve yedeklemeleri yürütür. Kuyruğa alınan işler için ayrı bir worker gerekmez; aynı cron satırı onları da işler.

    Terminal
    $ cd /var/www/pnlcs
$ WEB_USER=www-data   # AlmaLinux, Rocky: apache
$ (sudo crontab -u $WEB_USER -l 2>/dev/null; echo '* * * * * cd /var/www/pnlcs && php artisan schedule:run >> /dev/null 2>&1') | sudo crontab -u $WEB_USER -

$ sudo apt install -y certbot python3-certbot-nginx   # Ubuntu, Debian
$ sudo certbot --nginx -d example.com
$ pn sed -i 's|^APP_URL=http://|APP_URL=https://|' .env
$ pn php artisan optimize
