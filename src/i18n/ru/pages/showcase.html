Добавить компанию

Список компаний хранится в файле в репозитории этого сайта. GitHub может открыть pull request за вас прямо в браузере; ничего устанавливать не нужно.

Редактировать файл со списком компаний Полная инструкция
  1. Откройте файл со списком компаний на GitHubКнопка открывает его в редакторе. В первый раз GitHub создаёт копию в вашем аккаунте.
  2. Добавьте свою записьНазвание, сайт, что вы продаёте и какие модули используете. Описание должно быть короче 400 символов.
  3. Откройте pull requestАвтоматическая проверка собирает сайт с вашей записью. Мейнтейнер просматривает её и выполняет слияние.
