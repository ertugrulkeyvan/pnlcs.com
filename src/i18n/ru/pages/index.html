Биллинг с открытым исходным кодом для хостинг-компаний

Бесплатная альтернатива WHMCS, которая работает на вашем сервере. Счета, домены, SSL, тикеты поддержки, виртуальный хостинг, Docker-приложения и VPS на Proxmox в одном приложении. Проект поддерживают команда Panelica и добровольцы.

Что происходит при продлении

PNLCS выполняет биллинг по расписанию, поэтому никому не нужно помнить об отправке счёта или об отключении неоплаченного аккаунта. Ниже значения по умолчанию; каждое число настраивается.

Жизненный цикл биллинга в документации

  1. За 14 дней

    Счёт на продление

    Создаётся и отправляется клиенту по email.

    invoice_days_before_due = 14

  2. За 3 дня

    Списание с сохранённой карты

    Если вы включили автосписание. До 3 попыток с интервалом в 3 дня.

    AutoChargeDaysBefore = 3

  3. День оплаты

    Напоминания

    Неоплаченные счета становятся просроченными, клиентам уходят напоминания. Через 3 дня может начисляться пеня, если вы её включили.

    LateFeeMinDays = 3

  4. Через 3 дня

    Приостановка

    Услуга приостанавливается на сервере. После оплаты она возобновляется в течение 30 минут.

    AutoSuspensionDays = 3

  5. Через 30 дней

    Удаление

    Только если вы это включите. По умолчанию выключено.

    AutoTerminationDays = 30

Установка через Docker

Один контейнер приложения и один контейнер базы данных. Остальное сделает мастер установки.

  1. Запустите контейнерыСначала замените changeme на собственные пароли.
  2. Подождите от 3 до 5 минутПри первом запуске устанавливаются зависимости и собирается фронтенд.
  3. Откройте /installМастер проверит требования, создаст аккаунт администратора и затем заблокирует себя.

Другие способы установкиИли сначала откройте демо

Терминал
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
