Альтернатива WHMCS с открытым исходным кодом

PNLCS намеренно повторяет WHMCS: клиенты, продукты, заказы, счета, услуги, тикеты и модули означают то же самое. Разница в лицензии: PNLCS распространяется под MIT, без платы за каждую установку.

Что переносится из WHMCS

Понятия
Группы продуктов, продукты, настраиваемые опции, услуги, заказы, счета, кредит, тикеты и отделы работают так, как привыкли сотрудники, знакомые с WHMCS.
Имена действий API
HTTP API использует имена действий WHMCS, поэтому большинству интеграций нужны только новый адрес и новые учётные данные.
Хуки
add_hook('InvoicePaid', 1, fn) работает так же; хук с ошибкой записывается в журнал и пропускается, а не ломает биллинг.
Модули
Серверы, платёжные шлюзы, регистраторы и SSL-провайдеры реализованы отдельными модулями, как в WHMCS.

Переход без простоя

Запустите PNLCS рядом с WHMCS и переводите клиентов по мере продления. Аккаунты всё это время остаются на тех же серверах.

Импорта в один клик пока нет

В PNLCS нет автоматического импорта базы данных WHMCS. Описанные здесь шаги представляют собой практичный и малорискованный способ переезда. Импорт будет желанным вкладом в проект.

  1. Воссоздайте каталогСоздайте группы продуктов и продукты с теми же названиями и ценами.
  2. Подключите те же серверыАккаунты на них уже есть; с этого момента ими управляет PNLCS.
  3. Перенесите настройкиПлатёжные шлюзы (те же аккаунты), налоговые правила, шаблоны писем, сотрудники и роли.
  4. Перенесите клиентовДобавьте каждого клиента и его текущие услуги с правильной датой следующей оплаты. На Panelica привяжите аккаунт, который уже есть на сервере.
  5. ПереключитесьПри продлении, по одному клиенту, или всех сразу во время окна обслуживания.
