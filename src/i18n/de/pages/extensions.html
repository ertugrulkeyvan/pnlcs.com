Ihr Modul oder Theme eintragen

Die Liste ist eine Datei im Repository dieser Website. Kostenlos oder kostenpflichtig, Open oder Closed Source: Alles, was für PNLCS gebaut ist, kann gelistet werden. Verkauft wird auf Ihrer eigenen Website.

Listendatei bearbeiten Vollständige Anleitung
  1. Listendatei auf GitHub öffnenDie Schaltfläche öffnet sie im Editor. Beim ersten Mal legt GitHub eine Kopie in Ihrem Konto an.
  2. Eintrag hinzufügenName, eine kurze Zusammenfassung, die Preisart, die Lizenz, die passende PNLCS-Version und die Seite, auf der man es bekommt.
  3. Pull Request öffnenEine automatische Prüfung erstellt die Website mit Ihrem Eintrag. Ein Maintainer sieht ihn durch und führt den Merge durch.
