Unternehmen eintragen

Die Referenzen sind eine Datei im Repository dieser Website. GitHub kann den Pull Request für Sie im Browser öffnen; Sie müssen nichts installieren.

Referenzdatei bearbeiten Vollständige Anleitung
  1. Referenzdatei auf GitHub öffnenDie Schaltfläche öffnet sie im Editor. Beim ersten Mal legt GitHub eine Kopie in Ihrem Konto an.
  2. Eintrag hinzufügenName, Website, was Sie verkaufen und welche Module Sie nutzen. Die Beschreibung muss unter 400 Zeichen bleiben.
  3. Pull Request öffnenEine automatische Prüfung erstellt die Website mit Ihrem Eintrag. Ein Maintainer sieht ihn durch und führt den Merge durch.
