Was bei einer Verlängerung passiert

PNLCS führt die Abrechnung nach Zeitplan aus, damit niemand daran denken muss, eine Rechnung zu senden oder ein unbezahltes Konto abzuschalten. Dies sind die Standardwerte; jede Zahl ist eine Einstellung.

Abrechnungszyklus in der Doku

  1. 14 Tage vorher

    Verlängerungsrechnung

    Wird erstellt und per E-Mail an den Kunden gesendet.

    invoice_days_before_due = 14

  2. 3 Tage vorher

    Hinterlegte Karte belastet

    Wenn Sie den automatischen Einzug aktivieren. Bis zu 3 Versuche im Abstand von 3 Tagen.

    AutoChargeDaysBefore = 3

  3. Fälligkeit

    Erinnerungen

    Unbezahlte Rechnungen werden überfällig, und Erinnerungs-E-Mails gehen raus. Nach 3 Tagen fällt eine optionale Mahngebühr an.

    LateFeeMinDays = 3

  4. 3 Tage danach

    Gesperrt

    Der Dienst wird auf dem Server gesperrt. Nach der Zahlung wird er innerhalb von 30 Minuten entsperrt.

    AutoSuspensionDays = 3

  5. 30 Tage danach

    Gekündigt

    Nur wenn Sie es aktivieren. Standardmäßig aus.

    AutoTerminationDays = 30

Jeden Morgen, in dieser Reihenfolge

Die Reihenfolge ist wichtig. Ein Kunde, dessen hinterlegte Karte um 06:45 belastet wird, wird um 07:00 nie gesperrt und um 08:00 nicht an die Zahlung erinnert.

06:00Verlängerungsrechnungen des Tages erstellenpnlcs:generate-invoices
06:30Unbezahlte Rechnungen als überfällig markierenpnlcs:mark-overdue
06:45Hinterlegte Karten belastenpnlcs:auto-charge
07:00Dienste nach Ablauf der Kulanzfrist sperrenpnlcs:auto-suspend
07:30Mahngebühren berechnenpnlcs:apply-late-fees
08:00Zahlungserinnerungen sendenpnlcs:payment-reminders

In etwa 5 Minuten einsatzbereit

Ein Docker-Image und ein Datenbank-Container. Den Rest erledigt der Installationsassistent.

  1. Container startenErsetzen Sie zuerst changeme durch eigene Passwörter.
  2. 3 bis 5 Minuten wartenBeim ersten Start werden Abhängigkeiten installiert und das Frontend gebaut.
  3. /install öffnenDer Assistent prüft die Voraussetzungen, legt Ihr Admin-Konto an und sperrt sich danach selbst.

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
