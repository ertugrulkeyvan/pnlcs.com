Ihr erster Pull Request

  1. Etwas Kleines auswählenEin offenes Issue oder etwas, das Sie in der Demo gestört hat.
  2. Forken und Branch anlegenStarten Sie das Projekt lokal mit Docker, wie in der Doku beschrieben.
  3. Pull Request öffnenBeschreiben Sie, was Sie geändert haben und warum. Kleine Pull Requests werden am schnellsten geprüft.
  4. MergeEin Maintainer prüft ihn. Übernommene Änderungen kommen ins nächste Release, und Sie werden in der Historie genannt.
