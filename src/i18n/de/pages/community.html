Aktuell besonders gesucht

Code, der existiert, aber noch nicht auf echten Systemen gelaufen ist.

Integrationsstatus
  • cPanel, Plesk und DirectAdminSetzen Sie das Servermodul auf Ihrem Panel ein und berichten Sie, was passiert ist.
  • PayPal, Authorize.net, BanküberweisungFühren Sie eine Testzahlung von Anfang bis Ende durch.
  • EnomRegistrieren und verlängern Sie eine Domain über die echte API.
  • Ein WHMCS-ImporterDen gibt es noch nicht. Der Migrationsleitfaden ist der Ausgangspunkt.

Ihr erster Pull Request

  1. Etwas Kleines auswählenEin offenes Issue oder etwas, das Sie in der Demo gestört hat.
  2. Forken und Branch anlegenStarten Sie das Projekt lokal mit Docker, wie in der Doku beschrieben.
  3. Pull Request öffnenBeschreiben Sie, was Sie geändert haben und warum. Kleine Pull Requests werden am schnellsten geprüft.
  4. MergeEin Maintainer prüft ihn. Übernommene Änderungen kommen ins nächste Release, und Sie werden in der Historie genannt.
