Installer PNLCS

PNLCS est une application Laravel. Elle fonctionne partout où PHP 8.4, MySQL ou MariaDB et un serveur web sont disponibles. Pour faire d’abord le tour du produit, la démo en ligne est une vraie installation.

Démarrage rapide avec Docker

L’image officielle embarque PHP-FPM 8.4, nginx, Node.js 20 et supervisor, et récupère la dernière version du code au premier démarrage.

  1. Lancez les conteneursRemplacez d’abord changeme par vos propres mots de passe.
  2. Patientez 3 à 5 minutesLe premier démarrage installe les dépendances et compile le frontend.
  3. Ouvrez /installL’assistant vérifie les prérequis, crée votre compte administrateur, puis se verrouille.

Guide DockerImage sur Docker Hub

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4

Prérequis

Une petite installation tourne confortablement avec 2 Go de mémoire et la base de données sur la même machine.

Prérequis complets

PHP8.4 ou plus récent
Base de donnéesMySQL 8.0 ou MariaDB 10.6+
Serveur webNginx ou Apache avec PHP-FPM
Node.js18+ (20 LTS recommandé), uniquement pour compiler le frontend
Composer2.x
Mémoire1 Go suffit pour une petite installation ; 2 Go offrent du confort
DisqueEnviron 130 Mo pour l’application ; prévoyez au moins 2 Go libres, car les données augmentent
