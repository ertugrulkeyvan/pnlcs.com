Applications Docker

Les clients installent WordPress, n8n, des bases de données ou des bureaux à distance depuis un catalogue. Chaque application tourne sous forme de conteneurs Docker dans le compte d’hébergement du client, dans la limite de la mémoire et du CPU de son offre. Nécessite un serveur Panelica.

Guide : vendre des applications Docker

Trois façons de vendre des applications

Elles peuvent être combinées.

Hébergement avec applications incluses
Une offre d’hébergement classique avec un quota de conteneurs. Les clients ont un site web et peuvent ajouter des applications depuis l’onglet Applications à tout moment.
Hébergement d’application
La commande installe une application sur le domaine du client. Imposez l’application (« WordPress infogéré ») ou laissez le client choisir dans votre catalogue : un seul produit couvre alors toutes les applications.
Offre conteneurs
Des ressources sans site web : pas de domaine, et la page du service n’affiche que l’onglet Applications.

Les applications d’un compte partagent une même limite cgroup

Chaque conteneur lancé par un client est créé dans la slice cgroup de son compte. Un client avec une offre de 2 Go dispose de 2 Go pour l’ensemble de ses applications et ne peut pas utiliser la mémoire d’un autre client.

  • Aucun conteneur privilégié, aucune capability supplémentaire ni aucun montage de chemin de l’hôte, même pour la clé de facturation
  • Les offres fixent le nombre d’applications, la mémoire totale et le CPU total
  • Les clients voient les besoins en mémoire d’une application avant de commander
  • Une commande qui ne parvient pas à installer son application est annulée, jamais laissée à moitié construite

Vous composez le catalogue

Le serveur Panelica détermine quelles applications existent. PNLCS détermine comment vous les vendez : quelles applications vous proposez, lesquelles sont mises en avant, leur ordre, leur accroche et leur logo.

  1. Connectez un serveur PanelicaAvec une clé d’API qui dispose des scopes Docker.
  2. Choisissez le mode de venteInclus, hébergement d’application ou offre conteneurs.
  3. Créez le produitDéfinissez le quota de conteneurs, la mémoire et le CPU, puis le prix.
  4. Composez le catalogueProposez, mettez en avant et ordonnez les applications ; 95 sur 98 ont un logo d’origine.
