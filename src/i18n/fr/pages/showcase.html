Les références sont un fichier du dépôt de ce site. GitHub peut ouvrir la pull request pour vous depuis le navigateur ; vous n’avez rien à installer.

Modifier le fichier des références Instructions complètes
  1. Ouvrez le fichier des références sur GitHubLe bouton l’ouvre dans l’éditeur. La première fois, GitHub crée une copie dans votre compte.
  2. Ajoutez votre entréeNom, site web, ce que vous vendez et les modules que vous utilisez. La description doit faire moins de 400 caractères.
  3. Ouvrez une pull requestUne vérification automatique construit le site avec votre entrée. Un mainteneur la relit et la fusionne.
