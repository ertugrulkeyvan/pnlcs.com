Votre première pull request

  1. Choisissez quelque chose de simpleUne issue ouverte, ou un détail qui vous a gêné dans la démo.
  2. Forkez et créez une brancheLancez le projet en local avec Docker, en suivant la documentation.
  3. Ouvrez une pull requestExpliquez ce que vous avez modifié et pourquoi. Les petites pull requests sont relues le plus vite.
  4. Faites-la fusionnerUn mainteneur la relit. Les modifications fusionnées entrent dans la version suivante, et vous êtes crédité dans l’historique.
