Le déroulement d’un renouvellement

PNLCS exécute la facturation selon un planning : personne n’a à penser à envoyer une facture ou à couper un compte impayé. Voici les valeurs par défaut ; chaque chiffre est un réglage.

Le cycle de facturation dans la documentation

  1. 14 jours avant

    Facture de renouvellement

    Créée et envoyée par e-mail au client.

    invoice_days_before_due = 14

  2. 3 jours avant

    Carte enregistrée débitée

    Si vous activez le prélèvement automatique. Jusqu’à 3 tentatives, à 3 jours d’intervalle.

    AutoChargeDaysBefore = 3

  3. Date d’échéance

    Relances

    Les factures impayées passent en retard et les e-mails de relance partent. Une pénalité de retard facultative s’applique après 3 jours.

    LateFeeMinDays = 3

  4. 3 jours après

    Suspendu

    Le service est suspendu sur le serveur. Un paiement le réactive dans les 30 minutes.

    AutoSuspensionDays = 3

  5. 30 jours après

    Résilié

    Seulement si vous l’activez. Désactivé par défaut.

    AutoTerminationDays = 30

Installation avec Docker

Un conteneur d’application et un conteneur de base de données. L’assistant d’installation fait le reste.

  1. Lancez les conteneursRemplacez d’abord changeme par vos propres mots de passe.
  2. Patientez 3 à 5 minutesLe premier démarrage installe les dépendances et compile le frontend.
  3. Ouvrez /installL’assistant vérifie les prérequis, crée votre compte administrateur, puis se verrouille.

Autres méthodes d’installationOu essayez d’abord la démo en ligne

Terminal
$ docker network create pnlcs-net

$ docker run -d --name pnlcs-db --network pnlcs-net \
  -e MYSQL_ROOT_PASSWORD=changeme \
  -e MYSQL_DATABASE=pnlcs -e MYSQL_USER=pnlcs \
  -e MYSQL_PASSWORD=changeme \
  mariadb:11

$ docker run -d --name pnlcs --network pnlcs-net \
  -p 8090:80 \
  -e DB_HOST=pnlcs-db -e DB_DATABASE=pnlcs \
  -e DB_USERNAME=pnlcs -e DB_PASSWORD=changeme \
  -e APP_URL=http://localhost:8090 \
  panelica/pnlcs-runtime:1.4
